前置条件

选择一台机作为面板机，然后域名指向这台机，开启小黄云，记得cloudflare中把网络-gRPC打开，这样就不需要如Wiki 所说需要两个域名分别作为通讯和访问域名了。

面板机我用nginx开了ssl，感觉不配置nginx、cf ssl开灵活模式应该也能通讯到agent（

Dashboard安装

官方一键脚本

1

curl -L https://raw.githubusercontent.com/nezhahq/scripts/refs/heads/main/install.sh -o nezha.sh && chmod +x nezha.sh && sudo ./nezha.sh

如果本机不配nginx，最好把端口设为80，方便cf代理成443。

然后登录https://域名/dashboard默认账密都是admin

右上角系统设置 Agent对接地址【域名/IP:端口】填入你的域名:443并开启使用TLS连接。

Agent安装

https://域名/dashboard 可以快捷复制agent安装命令

安装完成后可以在/opt/nezha/agent/config.yml修改一些设置

禁用自动更新
禁用webssh
禁用强制更新

1
2
3
4

sed -i 's/disable_auto_update: false/disable_auto_update: true/' /opt/nezha/agent/config.yml && \
sed -i 's/disable_command_execute: false/disable_command_execute: true/' /opt/nezha/agent/config.yml && \
sed -i 's/disable_force_update: false/disable_force_update: true/' /opt/nezha/agent/config.yml && \
systemctl restart nezha-agent
